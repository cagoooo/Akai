Sentry [JAVASCRIPT-REACT-X](https://smes.sentry.io/issues/7787517836/) 的事件 `346f183cf0494c07bcdd599e205bd7c0`：2026-10-12 15:52:48.310（臺北）、release 3.6.148、production、1 事件／1 使用者，來源為 `[useFavorites] onSnapshot 失敗`、`permission-denied`。通知文字的 environment unknown 與實際事件 production 不同；本輪未修改告警設定。

原程式在非同步匯入後沒有再次確認 effect 是否已取消；訂閱錯誤回呼也沒有確認身分。這可造成身分交接期間舊訂閱繼續使用前一個 UID。時序符合本事件，但沒有舊訂閱 UID 或 request ID 證據，未宣稱已實際重現這筆事件。

修正後在讀寫、訂閱及回呼前核對目前 Firebase 身分與 effect 生命週期；舊結果不套用、不建立殘留訂閱。雲端讀取失敗不當作空清單覆寫；當前帳號真正的權限錯誤仍回報，未放寬規則、未關閉 Sentry。保留匿名使用者本人收藏用途。

隔離測試涵蓋匿名合法同步、卸載後晚到讀取、登入換身分的舊錯誤、新帳號建立訂閱、真實當前錯誤保留、讀取拒絕後不覆寫。本機及 CI 結果、正式資產驗收另附發布證據。未用正式收藏、真實登入操作或實體裝置重現；舊 Sentry 事件保持原狀，未手動結案。
